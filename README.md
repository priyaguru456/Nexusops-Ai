# NexusOps AI
Enterprise operations platform with an AI assistant that answers
questions from company documents, with source citations.

## Stack
React, TypeScript, Node.js, Express, PostgreSQL (pgvector), LLM API

## Run locally
Terminal 1: cd apps/api && npm run dev
Terminal 2: cd apps/web && npm run dev
API health check: http://localhost:4000/api/health
Web app: http://localhost:5173
